# 1단계 공고 자격조건 조사 결과 (pdf 104건)

- 대상: `ai/data/survey.csv` 중 `format=pdf` 104행 (기업마당 소상공인 공고 222건 중 pdf 전부). 조사 열 채움, `surveyed=Y`.
- 방법: pdf 본문의 신청자격/지원대상/제외대상 섹션을 판독해 원문 기준으로 기록. hashTags는 `bizinfo_all.json`의 `hashtags` 키에서 직접 조회.
- 승격 기준: 공고 과반(≥53/104)에 등장 + 유저 정보(지역·업력·업종·근로자수·매출·대표자 특성)와 기계적 비교 가능.

## 0. 데이터 이슈
- `survey.csv`의 `hashTags` 열이 222행 전부 비어 있음. json 키가 `hashtags`(소문자)여서 적재 스크립트가 누락한 것으로 보임. 기존 열은 건드리지 않았고, 이 문서의 region_match는 json을 직접 조회해 판정.
- 104건 중 5건은 "소상공인 사업자 자격"이 아닌 다른 축이 핵심: 126148(근로자·양육자 대상 아이돌봄), 126059·126058·125893(상생보험: 대표자 연령·대출 보유), 117016(26개 사업 통합공고), 124909(15종 정책자금 통합). 집계에는 포함했으나 hard filter 설계 시 예외 처리 대상.

## 2. region_match — hashTags를 지역 필터로 신뢰할 수 있는가

| 판정 | 건수 | 비율 |
|---|---|---|
| Y (시도/시군구 단위까지 일치) | 71 | 68.3% |
| Y-전국 (17개 시도 전부 태그 + 지역조건 없음) | 21 | 20.2% |
| N-좁음 (실제 조건이 태그보다 좁음) | 7 | 6.7% |
| N-태그오류 | 5 | 4.8% |

- 일치(Y+Y-전국) 92/104 = 88.5%.
- N-좁음 7건: 읍면동·집적지·상권·시설 단위(용인 기흥 9개 동, 시흥 정왕 집적지구 2, 대전 인쇄집적지, 대전 전통시장 소속, 전북희망센터 입주, 서초구[태그는 서울만]). 태그가 더 넓으므로 필터 결과에 "해당 안 되는 후보"가 섞이는 방향(false positive) → LLM 검증에서 걸러지므로 위험 낮음.
- N-태그오류 5건:
  - 124890: 태그 `대구·유성구`, 공고는 대전 유성구 → 시도 오기. 대전 유저에게 노출 안 됨(false negative).
  - 121288: 태그 `부산`, 자격은 "국내 소상공인" → 타 지역 유저에게 노출 안 됨(false negative).
  - 122373·121231: 태그가 17개 시도 전부 + 과천시/광주 → 전국 처리 시 false positive.
  - 124840: 본문 지역 문구 없음(대전지식재산센터 관할 추정). 판정 애매.
- 부수 오류: 태그 오타 `천양군`(126079), 태그에 무관 시도 `충북` 혼입(125620), 광주, 전남, 전남광주통합특별시 -> 전남 광주로 정규화, 태그 시군구 없이 시도만인데 공고는 구 단위(125560).
- 판단: **시도 단위 hard filter로는 신뢰 가능**(오류율 ~3%, 그중 false negative 2건). **시군구 단위 필터는 태그만으로는 부적절** — 시군구 태그가 있어도 실제 조건이 읍면동/집적지인 경우와 태그가 시도만인 경우가 섞여 있음. 권고: 적재 시 본문에서 LLM으로 `region_sido / region_sigungu / region_sub(읍면동·상권 원문)`을 추출하고, 추출 실패 시에만 hashTags를 fallback으로 사용. "17개 시도 전부" 태그는 `전국` 플래그로 정규화.

## 5. 파싱 난점 요약
- 표 비율: 자격·지원내용이 표 형태인 공고 67/104 (64%). 경북 카드수수료 계열은 "사업개요"가 세로 표(항목명 좌측 열)로 되어 있어 행 단위 추출 시 키-값 결합 필요(16건).
- [스캔] 이미지 pdf 14건 (13.5%): 포스터형 8, 웹페이지 캡처형 3, 전 페이지 스캔 3(125449 등). OCR 필수. 00_precheck의 "이미지 6건"과 별개로 pdf 안에 숨은 이미지 공고가 이만큼 더 있음 → 실제 OCR 대상은 20건 내외.
- 텍스트 레이어는 있으나 글자 순서가 뒤섞인 pdf 9건 (경북경제진흥원·울산·대전 계열 hwp→pdf 변환물: 126215·126212·125962·125890·125057·125055·124840·117221·117167). pdftotext 결과를 그대로 청킹하면 문장이 깨짐 → 레이아웃 보존 옵션(`-layout`) 또는 이미지 렌더 후 OCR로 우회 필요.
- 조건이 붙임/별표에만 있는 경우: 제외업종 목록(경북 카드수수료 붙임1, 정책자금 별표1 등) 다수가 pdf에 미포함. 첨부파일(`attach_name`)까지 파싱하거나 표준 목록으로 대체해야 함.
- 통합·다트랙 공고: 117016(26개 사업), 124909(15종 자금), 120174(4개 유형), 117221(3개 트랙), 121366(2개 Track)은 단일 자격 행으로 표현 불가. 공고를 세부사업 단위로 분할 적재하거나 LLM 검증 전용으로 분류.
- 공고문에 시도명이 없고 "관내/도내"로만 표기된 건(122254·121804·121193 등) → 발행기관(`org`)으로 보정 필요.
